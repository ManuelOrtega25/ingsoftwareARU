Resumen del Escaneo Dinamico (DAST)

Se ejecuto un escaneo activo sobre los endpoints de la API y vistas web: /api/auth/*, /api/donaciones, /api/instituciones. Las pruebas incluyeron inyecciones SQL (SQLi), Cross-Site Scripting (XSS), seguridad de cabeceras HTTP y control de sesiones JWT.

Evidencia de Mitigacion Implementada

Se integro la libreria Helmet en Express y se creo la funcion de sanitizacion para campos de texto antes del guardado:

app.use(helmet({ contentSecurityPolicy: true }));
function sanitizarTexto(t) { return t.replace(/</g, '&lt;').replace(/>/g, '&gt;'); }
